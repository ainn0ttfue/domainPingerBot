# domainPingerBot

Telegram бот для проверки доступности сайтов.
Бот оповестит вас, если ваш сайт(ы) стали недоступны (error 4XX & 5XX), а
также сообщит код и время появления ошибки.

> Внимание! Обращаю внимание, что в данной итерации все домены указаны локально (не в БД, и ID юзера, который может пользоваться ботом, тоже харадкожен в переменных окружения (остальным пользователям выводится сообщение "Access Denied")

Рабочий бот: https://t.me/domainsPingerBot

# Развертывание:

1. Токен бота и ID основного юзера нужно указать в переменных окружения функции yc:

2. Создать API Gateway следующего содержимого:
```
openapi: 3.0.0
info:
  title: Sample API
  version: 1.0.0
servers:
- url: <УНИКАЛЬНЫЙ URL>
paths:
  /:
    post:
      x-yc-apigateway-integration:
        payload_format_version: '0.1'
        function_id: <ID функции из шага один>
        tag: ''
        type: cloud_functions
```

3. Теперь нужно закрепить вебхук, чтобы телеграм знал, кто обрабатывает сообщения к боту.
Для этого нужно выполнить код ниже:
```
import telebot
bot = telebot.TeleBot("<ТОКЕН БОТА>")
bot.remove_webhook()
bot.set_webhook("https://<Уникальный URL API gateway из шага 2>")
```

Готово. Теперь бот будет работать.

> Есть сложности с обработкой доменов в зоне .рф - это связано с некорректной работой модуля whois (на версии 8.0 данного модуля все работает, но pthon 3.12 некорректно работает с данной версией модуля )
